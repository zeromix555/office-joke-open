# The Slide That Said It All

An entry for the [make.fun bounty "Make the AI Judge Laugh: the Office Joke Open"](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232) ($2 winner-takes-all).

## The joke

`main.ts` writes one line of office comedy to `/output/entry.txt`:

> Our standup meeting has a slide deck now. It has one slide: 'This could have been an email.'

## Run it

Requires Node 22+ (stdlib only, nothing to install):

```sh
node main.ts
```

Run it twice — the output is byte-identical every time (92 characters, one line).
